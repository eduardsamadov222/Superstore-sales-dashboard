# Superstore Sales - Interactive Analytics Dashboard

Hello! In this project, I built a zero-to-hero interactive sales analytics dashboard using classic Superstore data. My main goal was to transform raw data into a clean, visual, and readable report that helps drive real business decisions.

---

## Tools and Technologies Used
* **Microsoft Excel (.xlsm):** All calculations, Pivot Tables, and data relationships were built here.
* **Interactive Controls:** Real-time data filtering powered by Slicers and Timelines.
* **VBA (Macro):** Custom button script enabling a seamless full-screen mode for presentations.
* **Design:** Custom dark theme tailored to a corporate style with high-contrast KPI cards.

## Key Business Questions Addressed
* Which regions and product categories generate the highest revenue for the company?
* How do sales and profit metrics fluctuate across years and quarters?
* Which top-10 states or sub-categories should we focus on to optimize inventory and sales strategies?

---

## How to Use the File
1. Download the file from the repository (make sure it is in `.xlsm` format to support macro functionality).
2. When opening it in Excel, click "Enable Content" if a security warning appears at the top to activate the full-screen button.
3. Use the Slicers and Timelines on the right and top panels to dynamically filter and analyze the data.
