# Superstore Sales Interactive Dashboard 📊

> Professional Business Intelligence and Data Analytics project built in Microsoft Excel, featuring advanced interactive modeling, dynamic KPI tracking, and custom dark-theme UI design.

---

## 🚀 Project Overview
This repository contains an enterprise-grade interactive sales analytics dashboard developed using the **Superstore Dataset**. The solution is engineered to transform raw transactional data into actionable business insights through modern data visualization principles and automated reporting structures.

## 🛠️ Technical Stack & Features
* **Core Tool:** Microsoft Excel (`.xlsm` Macro-Enabled Workbook)
* **Data Modeling & Aggregation:** Pivot Tables, Advanced Calculated Fields, and Relational Data Modeling.
* **Interactivity:** Dynamic Slicers and Interactive Timeline Filters for real-time data slicing.
* **VBA Automation:** Custom macro implementation for seamless Full-Screen presentation mode.
* **UI/UX Design:** Custom Dark Theme corporate layout with high-contrast KPI cards and structured layout hierarchy.

## 💡 Key Business Questions Addressed
* **Revenue & Profitability:** Which regions and product categories drive the highest profit margins?
* **Temporal Trends:** How do quarterly and yearly sales performance metrics fluctuate?
* **Top Performers:** Identification of the top-performing states and sub-categories to optimize inventory distribution.

---

## 📌 Getting Started & Instructions
1. Download the repository files, ensuring you use the **`.xlsm`** format to preserve macro functionality.
2. Open the workbook in Microsoft Excel.
3. *Note on Macros:* If prompted by security notifications upon opening, click **"Enable Content"** in the yellow security bar to activate the interactive full-screen VBA script.
4. Use the Slicers and Timeline controls to explore regional and temporal data breakdowns dynamically.
